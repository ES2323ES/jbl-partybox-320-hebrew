# JBL PartyBox Stage 320 — מרכז שליטה בעברית (גרסה `0.2.2`)

אפליקציית שליטה ייעודית ומלאה בעברית (RTL) עבור הרמקול הנייד **JBL PartyBox Stage 320**, בעיצוב סטודיו נעים ורך לעין (תצוגת יום רכה + תצוגת ערב נעימה), שליטה מלאה בתאורת המופע הרב-אזורית, איקוולייזר 7 ערוצים אינטראקטיבי, חיבור והרשאות **Bluetooth** מלאות לרמקול, וחבילת התקנה מקומפלת לאנדרואיד (**APK** + **ZIP**).

## חידושים בגרסה `0.2.2`

- **עיצוב חדש ונעים לעין**: מעבר מפלטה שחורה מסנוורת למערכת צבעי סטודיו רכה ומאוזנת (**Soft Daylight Studio** כברירת מחדל + מצב **Soft Evening Slate** נעים לחדרים חשוכים בלחיצה אחת).
- **הרשאות ואינטגרציית Bluetooth מלאה לרמקול הנייד**:
  - הרשאות אנדרואיד מלאות (`BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION`, `MODIFY_AUDIO_SETTINGS`, `RECORD_AUDIO`).
  - גשר חומרה מובנה ב-APK (`JblAndroidBridge`) לזיהוי רמקולי JBL מזווגים, פתיחה מהירה של הגדרות ה-Bluetooth לזיווג, שליטה בעוצמת השמע הפיזית של הרמקול (`STREAM_MUSIC`) וחיבור מנוע איקוולייזר ו-BassBoost מערכתי.
- **מפתח קבוע ב-GitHub וניהול גרסאות אוטומטי (`v2`, `v3`, `v4`...)**:
  - שמירת מפתח קבוע (`Deploy Key` + אסימון חיבור קבוע) להעלאת עדכונים ללא צורך באימות חוזר.
  - בכל עדכון לענף `main` נוצר אוטומטית שחרור גרסה ממוספר חדש (`v2`, `v3`, `v4` וכן הלאה) כולל קובצי ה-`APK` וה-`ZIP` המעודכנים.

## יכולות מרכזיות

- **הדמיית חומרה חיה (Stage 320 Live Visualizer)**: טבעות שמינייה כפולות סביב זוג הוופרים בקוטר 6.5 אינץ׳ המגיבים פיזית לתדרי הבס, מבזקי סטרוב, כוכבים ופסי צד.
- **סטודיו תאורת מופע (Lightshow)**: 6 מצבי תנועה ייעודיים, שליטה נפרדת על 5 אזורי תאורה בתיבה, בורר צבעים דו-גווני וסנכרון לקצב (**Beat-Sync**).
- **איקוולייזר 7 ערוצים ומנוע DSP חי**: ערוצי תדר `63Hz` עד `12kHz` בטווח `-12dB` עד `+12dB`, שמירת פרופילים אישיים, מצבי **JBL BassBoost** וכיול סביבת הצבה.
- **משטח PartyPad™ ומיקסר קריוקי/גיטרה**: 6 משטחי סאונד DJ בסינתזה חיה, כניסות מיקרופון וגיטרה עם אפקט Echo, ניהול סוללת **JBL Battery 400** והגדרות **Auracast™**.
- **חבילת אנדרואיד מקומפלת (`0.2.2`)**: זמינה בנתיבים `public/JBL-PartyBox-320-HE.apk` ו-`public/JBL-PartyBox-320-HE-APK.zip`.

## הפעלה מקומית

```bash
npm install
npm run dev
```

השרת פועל בכתובת `http://localhost:3000`.
