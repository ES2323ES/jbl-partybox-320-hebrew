# JBL PartyBox Stage 320 — מרכז שליטה בעברית

אפליקציית שליטה ייעודית ומלאה בעברית (RTL) עבור הרמקול הנייד **JBL PartyBox Stage 320**, הכוללת שליטה בזמן אמת על תאורת המופע הרב-אזורית, איקוולייזר 7 ערוצים אינטראקטיבי, מצבי הדגשת בס (**BassBoost**), אפקטי **PartyPad™ DJ**, מיקסר כניסות מיקרופון/גיטרה וחבילת התקנה מקומפלת לאנדרואיד (**APK**).

## יכולות מרכזיות

- **הדמיית חומרה חיה (Stage 320 Live Visualizer)**:
  - תצוגת רמקול אינטראקטיבית עם טבעות שמינייה כפולות (Figure-8) סביב זוג הוופרים בקוטר 6.5 אינץ׳ המגיבים פיזית לתדרי הבס, מבזקי סטרוב עליון ותחתון, מטריצת כוכבים ופסי צד.
- **סטודיו תאורת מופע (Lightshow)**:
  - 6 מצבי תנועה ייעודיים: `רוק (Rock)`, `זרימה (Flow)`, `חצייה (Cross)`, `אדוות (Ripple)`, `מבזק מועדון (Flash)` ו-`תאורת אווירה קבועה`.
  - שליטה נפרדת על 5 אזורי תאורה בתיבה, בורר צבעים דו-גווני, בהירות, מהירות תנועה, תדירות סטרוב וסנכרון אוטומטי לקצב (**Beat-Sync**).
- **איקוולייזר 7 ערוצים ומנוע Web Audio DSP**:
  - ערוצי תדר `63Hz`, `125Hz`, `250Hz`, `500Hz`, `1kHz`, `4kHz`, `12kHz` בטווח `-12dB` עד `+12dB` עם גרף הענות תדרים משולב מנתח ספקטרום חי (FFT).
  - שמירת פרופילים אישיים, מצבי **JBL BassBoost** (`Deep 48Hz` / `Punchy 84Hz`), מעבד **AI Sound Boost** וכיול סביבת הצבה (חלל פנים / שטח פתוח).
- **משטח PartyPad™ ומיקסר קריוקי/גיטרה**:
  - 6 משטחי סאונד DJ בסינתזה חיה, כניסות מיקרופון וגיטרה עם אפקט Echo, ניהול סוללת **JBL Battery 400** (`Playtime Boost`) והגדרות **Auracast™**.
- **חבילת אנדרואיד מקומפלת (APK + PWA)**:
  - קובץ ההתקנה החתום לאנדרואיד זמין בנתיב `public/JBL-PartyBox-320-HE.apk` וכן בארכיון `public/JBL-PartyBox-320-HE-APK.zip`.

## הפעלה מקומית

```bash
npm install
npm run dev
```

השרת יעלה בכתובת `http://localhost:3000`.

## בנייה לסביבת ייצור

```bash
npm run build
npm start
```
