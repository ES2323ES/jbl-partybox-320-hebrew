# JBL PartyBox Stage 320 — אפליקציית שליטה Native בעברית (Android Java 17)

אפליקציית שליטה מלאה, מהירה, מודרנית ומינימליסטית לרמקול **JBL PartyBox Stage 320** בעברית מלאה (RTL).
האפליקציה לאנדרואיד כתובה ב-**100% Native Android (Java 17)** (ללא WebView וללא מעטפת HTML) עם אייקונים וקטוריים בפורמט **SVG (`VectorDrawable`)**, ביצועים מיידיים ומשקל קובץ מזערי (~75KB).

## מבנה המסכים והממשק (Native Android v0.4.0)

### סרגל עליון (כותרת האפליקציה)
- **צד ימין — הגדרות ומידע על הרמקול (`Settings`)**:
  - **מידע על הרמקול הנייד ועדכון קושחה ישיר**: הצגת דגם הרמקול, ערוץ תקשורת, סוללה, MAC, חומרה ו**גרסת הקושחה המותקנת ברמקול**, כולל בדיקת עדכון ואפשרות ישירה ל**עדכון קושחת הרמקול הנייד (OTA DFU)** במידה וקיים עדכון.
  - בחירת ערכת נושא: **מצב בהיר / מצב כהה / לפי מערכת**.
  - **עדכון אוטומטי לאפליקציה מ-GitHub Releases**: בדיקת תג ה-Release האחרון במאגר והורדה + התקנה בלחיצה אחת.
  - **מדריך שימוש ופירוט מלא** על האפליקציה והחיבור לרמקול.
- **צד שמאל — אודות (`About`)**:
  - קרדיט פיתוח ל-**״אש התורה״** עם קישורים ישירים לפרופיל ב-GitHub ובמתמחים טופ.
  - פירוט גרסת האפליקציה, מספר Build ורשימת **״מה חדש״**.

### שורה תחתונה קבועה (מימין לשמאל)
1. **חיבור ופרטי בוקסה (`חיבור`)**: סריקה וחיבור מהיר ל-JBL PartyBox 320 (BLE GATT + RFCOMM SPP + A2DP) והצגת שם הבוקסה, אחוז סוללה, גרסת קושחה, כתובת MAC ועוצמת קליטה (RSSI).
2. **שליטה וסנכרון תאורה מלא (`שליטה`)**: סנכרון תאורה דו-כיווני מלא בזמן אמת מול הרמקול (7 מצבי תאורה כולל **ניאון**, צבע ראשי ומשני, בהירות, מהירות, 5 אזורי תאורה ופעימת Beat Sync חיה לקצב השיר המתנגן), לצד עוצמה ראשית, מצבי Bass Boost וכניסת מיקרופון / אקו.
3. **איקוולייזר חומרתי (`איקוולייזר`)**: 7 ערוצי תדר (`63Hz`–`12kHz`) המחוברים ל-AudioFX החומרתי של אנדרואיד ולבוקסה, פרופילים מובנים ושמירת פרופילים אישיים.
4. **שירים — זיהוי אוטומטי מכל אפליקציה (`שירים`)**: ללא שום העלאת קבצים או בחירת תיקיות! הפעל מוזיקה מכל אפליקציה במכשיר (Spotify, YouTube Music, Apple Music, YouTube, SoundCloud, VLC ועוד) והאפליקציה קולטת אוטומטית שמתנגן שיר, מציגה את פרטיו, שולטת בניגון ומסנכרנת אליו את תאורת הרמקול.
5. **הגדרות הבוקסה (`הבוקסה`)**: שליטה בצלילי חיווי המערכת של הבוקסה, Playtime Boost, מצב אקוסטי פנים/חוץ, הגדרת סטריאו / Auracast ובחירת פרוטוקול שידור.

## בניית אפליקציית ה-Native באנדרואיד (Gradle)

הפרויקט בנוי כפרויקט Android Gradle תקני ומוכן לפתיחה ישירה ב-**Android Studio** או לבנייה מהטרמינל (JDK 17 + Gradle 8.9):

```bash
# הרצת בדיקות היחידה (JUnit) עבור סנכרון התאורה, עדכון הקושחה לרמקול ומנגנון ה-Releases
./gradlew testDebugUnitTest

# בניית קובץ APK חתום לייצור (Release)
./gradlew assembleRelease
```

קובץ ה-APK החתום נוצר בנתיב:
`app/build/outputs/apk/release/app-release.apk`
