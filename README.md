# JBL PartyBox Stage 320 — מרכז שליטה בעברית (גרסה `0.2.3` · `v3`)

אפליקציית שליטה ייעודית ומלאה בעברית (RTL) עבור הרמקול הנייד **JBL PartyBox Stage 320**, הכוללת 3 מצבי תאורת תצוגה (**יום בהיר**, **ערב רך**, ו**תאורת ניאון** זוהרת), שליטה מלאה בתאורת המופע הרב-אזורית של הרמקול, סצנות מסיבה חכמות, קריוקי חי מהטלפון, איקוולייזר 7 ערוצים עם כיול חדר אקוסטי, נגן פלייליסט עם **Crossfade**, סמפלר הקלטה אישי, שליטה מהירה מווילון ההתראות באנדרואיד, והרשאות **Bluetooth** מלאות לרמקול (**APK** + **ZIP**).

## חידושים בגרסה `0.2.3` (`v3`)

- **תאורת ניאון יפה (Neon Glow)**:
  - בלחצן התאורה העליון נוספה אופציית **תאורת ניאון** (לצד `יום בהיר` ו-`ערב רך`) הצובעת את סביבת העבודה בגווני ניאון ציאן (`#00F0FF`) ומג׳נטה (`#E838FF`) אלגנטיים ונעימים לעין.
  - ברמקול ובפקדי תאורת המופע נוסף אפקט **ניאון זוהר (Neon)** עם הילות ניאון דו-שכבתיות המסתובבות בכיוונים מנוגדים ופסי צד מוארים.
- **5 סצנות מסיבה חכמות + טיימר שינה הדרגתי (Sleep Fade-Out)**:
  - הפעלה בלחיצה אחת של: **מועדון ניאון זוהר**, **קבלת פנים רגועה**, **שיא מסיבה**, **במת קריוקי ושירה**, ו**מצב לילה לשכנים** (המוריד תדרי סאב-בס החודרים קירות).
  - טיימר דעיכה הדרגתי (`15` / `30` / `45` / `60` דקות) המנמיך את העוצמה ברכות בדקה האחרונה ומכבה את התאורה.
- **קריוקי חי מהטלפון + Auto MC Ducking**:
  - שירה והנחיה מהמיקרופון של הטלפון ישירות לרמקול ה-Bluetooth עם מסנן רעשים (`85Hz HPF`), כיוון בס/טרבל, אפקט **Echo** חי והנמכה אוטומטית של המוזיקה (`-10dB`) ברגע שמדברים למיקרופון.
- **נגן פלייליסט מרובה שירים עם Crossfade וכיול חדר אקוסטי (5 שניות)**:
  - טעינת רשימת שירים מלאה מהמכשיר עם מעבר DJ מדורג (3 שניות **Crossfade**) בין שירים.
  - **כיול חדר אקוסטי חכם**: השמעת צליל בדיקה ומדידת החזרי החדר דרך המיקרופון לכוונון אוטומטי של 7 ערוצי האיקוולייזר ומצב `חדר סגור` / `שטח פתוח`.
- **סמפלר אישי (4 משטחי הקלטה) + גיבוי JSON מלא**:
  - 4 משטחי **PartyPad** אישיים להקלטת הקול שלך (עד 4 שניות למשטח) הנשמרים קבוע במכשיר, לצד 6 אפקטי DJ מסונתזים.
  - ייצוא וייבוא קובץ גיבוי `JSON` מלא של כל הפרופילים, ההקלטות והגדרות התאורה.
- **שליטה מווילון ההתראות באנדרואיד, חיבור אוטומטי ובדיקת עדכוני GitHub**:
  - התראת שליטה מהירה באנדרואיד ומסך הנעילה (`Play/Pause`, `תאורת ניאון`, `הדגשת בס`, `השתקה`).
  - חיבור אוטומטי לרמקול המזווג האחרון ובדיקת גרסה חדשה מול מאגר ה-GitHub בלחיצה אחת.

## הפעלה מקומית

```bash
npm install
npm run dev
```
